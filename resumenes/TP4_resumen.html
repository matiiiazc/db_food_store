Parte 2 · Lectura crítica de planes interpretados por IA

Afirmación de la IA¿OK?Corrección / evidencia
"El plan usa Nested Loop para unir detalle_pedido con pedido"NoEl plan real usa Hash Join en los 3 nodos; no hay Nested Loop ni index lookups.
"La externa es detalle_pedido y se busca en pedido por índice"NoEn Hash Join no hay externa/interna: build = Hash sobre pedido, probe = detalle_pedido.
"El join con categoria es el más caro; cost 38088 es el tiempo"NoCategoria es un Hash de 4 filas; 38088 = costo estimado, no ms (tiempo real 4387 ms).
"La agregación ordena 600.000 filas por mes y categoría"SíSort ... external merge Disk: 20160kB + GroupAggregate con ese Group Key.
